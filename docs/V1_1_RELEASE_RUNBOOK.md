## STEP 3: スマホで確認する（15分）

### 3-1. アプリをダウンロードする

1. GitHub → `lanlangh/moffy` → 上のタブ **「Actions」**
2. 左のリストから **「Build AAB」** をクリック
3. 一番上の **「Build AAB #25」**（緑のチェックが付いているもの）をクリック
4. ページを一番下までスクロール →  **「Artifacts」** という欄に2つ並んでいます
5. **`moffy-release-apk`** のほうをクリックしてダウンロード（zip ファイルが落ちてきます）
6. zip を解凍すると `app-release.apk` というファイルが出てきます

> **なぜ APK のほう？**
> もう1つの `moffy-release-aab` は**ストア提出専用の形式**で、スマホに直接インストールできません。
> 手元で試すときは APK を使います。

### 3-2. Android スマホに入れる

1. `app-release.apk` を、スマホに送る（Google ドライブ、メール添付、USB ケーブルなど何でも可）
2. スマホでそのファイルを開く
3. **「提供元不明のアプリ」「この提供元のアプリを許可」** と聞かれたら**許可**する
   （自分でビルドしたアプリなので問題ありません）
4. インストール → 開く

> **⚠️ 安心して試してください。**
> このアプリは**ダミーのデータで動きます**（本番のデータベースに繋がりません）。
> 退会を試しても**本物のアカウントは消えません**。
> ※ 以前のバージョンでは退会だけ本物のデータベースを操作していましたが、
> 　 今回の v1.1 でそれを修正しました。

### 3-3. 3つだけ確認する

| # | やること | 期待する結果 |
|---|---|---|
| **A** | 下の **「メニュー」** タブを開く | **「対象アプリ」** という項目が**増えている**こと |
| **B** | 同じメニュー画面 | **「通知設定」が消えていて**、代わりに **「通知は今後のアップデートで」** という**押せない案内**になっていること |
| **C** | メニュー最下部の **「アカウント削除」** → 最後まで進む | 完了画面で **端末の「戻る」で前の画面に戻れない**こと。**「新しく始める」** を押すと**最初の説明画面から始まる**こと |

**さらに見ておくと良いもの（任意）**

| やること | 期待する結果 |
|---|---|
| 下の **「クエスト」** タブを開く | 「あと1日で ×1.0」という**意味のない表示が消えている**こと（「今日から◯日続けると ×1.2」のような表示になる） |
| メニュー →「対象アプリ」を開く | Android では「見守るアプリ」として4つのアプリが一覧表示される |

**iPhone をお持ちの場合**（※ iPhone 版のインストールは STEP 6 の TestFlight が必要です。いまは飛ばして構いません）

| やること | 期待する結果 |
|---|---|
| メニュー →「対象アプリ」→「アプリを選ぶ」 | **Apple のアプリ選択画面が開く**こと ← **これが今まで一度も存在しなかった導線です** |
| ホーム画面を見る | 「TikTok 0分／Instagram 0分…」という**チップが出なくなっている**こと |

### 3-4. 結果を AI に伝える

- 全部期待どおり → 「STEP 3 OK」と伝えてください
- 違うところがあった → **その画面のスクリーンショット**を送ってください

## STEP 4: 後片付け（必須・5分）⚠️ 忘れやすい

**なぜ必要か**: STEP 1（データベース更新）のとき、万一のために**変更前のデータのコピー**を
データベースの中に一時保管しました。これには全利用者の ID と残高が含まれます。
置きっぱなしにすると、**退会した方のデータが「30日以内に完全削除」されなくなり**、
利用者への約束（App Store の審査要件でもあります）が守れません。

**AI は Supabase を操作できないので、これはあなたにしかできません。**

1. ブラウザで **Supabase** にログイン（https://supabase.com/dashboard）
2. **Moffy のプロジェクト**を開く
3. 左のメニューから **「SQL Editor」**（アイコンは `>_` のような形）
4. 真ん中の空欄に、次の**1行だけ**を貼り付ける

   ```sql
   drop schema if exists ops cascade;
   ```

5. 右下の緑の **「Run」** ボタンを押す
6. **`Success. No rows returned`** と出れば完了です

> **赤い字でエラーが出たら**、繰り返し実行せずにスクリーンショットを AI に送ってください。

## STEP 5: Android をストアに出す

### 5-1. 本番用にビルドし直す（10分）

**⚠️ STEP 3 で使ったビルドは「テスト広告」版なので、そのまま出すと広告収入がゼロになります。**

1. GitHub → **Actions** → **「Build AAB」**
2. 右の **「Run workflow」**
3. **Branch: `v1.1-fixes`** を選ぶ
4. **「本番の実広告を出す」のチェックボックスに ✅ を入れる** ← STEP 3 のときと違う点はここだけ
5. 緑の **「Run workflow」** → 10分ほど待つ
6. 完了したら **Artifacts** から **`moffy-release-aab`**（今度は **AAB のほう**）をダウンロード・解凍

### 5-2. Play Console にアップロード

1. **Google Play Console** → **Moffy** を開く
2. 左メニュー **「テストとリリース」** → **「製品版」**
3. 右上の **「新しいリリースを作成」**
4. **「App Bundle」** の欄に、5-1 でダウンロードした `.aab` ファイルをドラッグ＆ドロップ
5. **「リリース名」**: `1.1.0` と入力
6. **「リリースノート」**（このリリースの新機能）に、次をコピーして貼り付け:

   ```
   ・メニューの統計が実際の記録を表示するようになりました
   ・iPhoneで対象アプリを選び直せるようになりました
   ・毎日の削減ポイントがたまごに正しく反映されるようになりました
   ・アカウント削除後の画面が正しく表示されるようになりました
   ・表示上の細かな不具合を修正しました
   ```

7. **「次へ」** → 内容を確認 → **「公開の概要」** → **「変更を送信して審査を受ける」**

> **注意**: 「新しいバージョンコードは既存より大きい必要があります」というエラーが出たら、
> ビルド番号がぶつかっています。AI に伝えてください（作り直します）。

## STEP 6: iOS をストアに出す

### 6-1. TestFlight 用にビルドする（20〜30分）

1. GitHub → **Actions** → **「iOS Build (macOS)」**
2. **「Run workflow」**
3. **Branch: `v1.1-fixes`**
4. **mode** の欄で **`testflight`** を選ぶ
5. **「本番の実広告を出す」に ✅ を入れる**（提出用なので）
6. **「Run workflow」** → 20〜30分待つ（iOS のビルドは時間がかかります）

完了すると、ビルドが自動的に App Store Connect にアップロードされます。

### 6-2. App Store Connect で提出する

**⚠️ 新しいバージョンを「作成」しないでください。**
App Store Connect は下書きを**同時に1つしか持てず**、すでに **1.0.3 の下書き**があります
（Apple のサブスク調査のために作ったものです）。それを使います。

1. **App Store Connect** → **Moffy**
2. 左メニューの **「1.0.3 プラットフォームバージョン」**（下書き）をクリック
3. **バージョン番号を `1.1.0` に書き換える**（下書きなので変更できます）
4. 下にスクロールして **「ビルド」** の欄で、6-1 でアップロードされたビルドを選ぶ
   （反映まで10〜30分かかることがあります。出てこなければ少し待って再読み込み）
5. **「このバージョンの新機能」** に、STEP 5-2 と同じ文章を貼り付ける
   **← ここが空だとエラーで提出できません（過去に実際に詰まった箇所です）**
6. 右上の **「保存」** → **「審査へ提出」**

> **サブスクについて**: Apple 側で固着している問題（ケース 20000121488355）は未解決のままです。
> **今回もサブスクは同梱せず、アプリ本体だけを提出します**。これは 1.0.2 のときと同じやり方で、
> そのときは審査を通過しています。
