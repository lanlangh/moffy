## 🎬 画像・リール（#001 の実測＋オーナーの制作条件を受けて確定）

### 差し替えの理由＝**#001 の Instagram は「1秒で捨てられた」**

| #001 の実測 | 読み |
|---|---|
| リールタブ 81% ＋ 発見 12.9% ＝ **94% がフォロー外** | **配信は開通している。抑制されていない** |
| **平均再生時間 1秒**（尺は**4秒**＝維持率25%） | 🔴 **Instagram が定めた「3秒の関門」の手前で終わっている** |
| 閲覧数119 ÷ 閲覧者104 ＝ **1.14** | ループがほぼ無い |
| **保存0 / フォロー0** | ⚠️ **判定材料にならない**（1秒で去った人に保存する機会は無い） |

> 🔴 **「不合格」の判定に外部ベンチマークは使わない（2026-08-18 訂正）。**
> 日本市場のリール視聴維持率のまともな統計は**存在しない**（日本語で出回る数字は全部SNS運用代行会社のブログで母数の記載が無い）。
> 代わりに使うのは**Instagram自身が2025年8月にインサイトへ追加した「スキップ率」＝表示から3秒以内に離脱した割合**という公式定義と、**自分の前回との比較**。

**構造的な原因**: #001 は **4秒間、画面が1ミリも変化しなかった**（静止画＋焼き込み文字なので t=0 と t=4 が完全に同一）。
**リールタブの視聴者は「動かないもの」を1秒で弾く。**

**対策は3つ**:
1. **文字を画像に焼き込まず、Instagram のテキスト機能で後乗せする**（ネイティブ投稿に見える／時間差で出せる／GPTの日本語描画失敗も消える）
2. **ペイオフ（見せ場）を離脱点より手前に置く。** #001 の離脱点は**1秒**。初稿は 2.7秒に置いていた＝**離脱点の1.7秒先にごほうびがあり、ほぼ全員が受け取れない**
3. **「文字なしの間」を作らない。** 間は「この先に何かある」と信じてもらえるアカウントだけの贅沢品で、**フォロワー実質1人のアカウントに残高が無い**

> 🎯 **#002 の通過点＝平均再生時間 2秒超え**（＝#001 の2倍）。いきなり尺の50%は届かない。

| 動画生成 | ⏸ **#002 では不採用**。理由は下記 |

### Instagram での作り方（アプリ内だけで完結・外部の動画編集アプリは不要）

```
1. Instagram → リールを作成 → ギャラリーを開く

   順番: 卵の寄り → ぷるりん → 顔の寄り → 引き

3. 「次へ」のあと「クリップを編集」を開き、1枚ずつの表示秒数を調整する
   目安: 1枚目=1.2秒 / 2枚目=1.4秒 / 3枚目=1.4秒 / 4枚目=1.5秒（合計5.5秒）

4. 音源を付ける
   Instagram公式の音源ライブラリから、静かでゆっくりした曲を選ぶ
   （外部から持ち込んだ音楽は使わない＝著作権）。音量は控えめに

5. テキストを4つ入れる（「Aa」のボタン）
   入力したあと、文字をタップして下のタイムラインで表示区間を指定します

   1枚目に重ねる: なにが出てくると思いますか
   2枚目に重ねる: この子でした
   3枚目に重ねる: ぷるりん、といいます
   4枚目に重ねる: 図鑑の、いちばん最初の子です

   ・文字は大きく、画面の中央あたりに置く
   ・画面のいちばん下から1/4には文字を置かない（キャプションと重なるため）

6. 4枚目の隅に、小さくもう1つテキストを入れる
   Moffy

7. カバー（表紙）は「1枚目の卵」に設定する

8. キャプションを貼り、タグ4個
