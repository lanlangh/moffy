- 返信が来るまで **1.0.3 は下書きのまま触らない**（審査へ提出しない）

  → **新しいバージョンを作ってはいけない**（ASC は下書きを同時に1つしか持てない）
- リリース番号を 1.1.0 にしたい場合は、下書きの versionString を書き換えるだけでよい
  （あわせて `pubspec.yaml` の version 前半を一致させる）
