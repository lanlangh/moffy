# Apple 指示の 1.0.3 サブスク追加テスト（手順書）

> 作成 2026-08-07 / ケース番号 **20000121488355**（担当: 桐畑・デベロッパサポート）
> 目的: 固着しているサブスク3点を、**GUIで**新バージョンの審査に追加できるかを確認し、Apple に報告する。

---

## 背景（なぜこれをやるのか）

Apple から 2026-08-07 に届いた指示の要点。

- **ASC API の 409 エラーはサポート対象外**と明言された。＝API経由の証拠は受け付けてもらえない。
- Apple 側の指摘: 「**App Store Connect のサイドバー 収益化 > サブスクリプション から、新規アプリバージョンの審査にサブスクリプションアイテムを追加された事を確認できませんでした**」
- 指示: **新規バージョン（1.0.3 等）を作成**し、公式手順「アプリ内購入の初回提出」「アプリ内購入またはサブスクリプションを既存の提出物に追加する」を実施できるか確認する。
  - 参考: https://developer.apple.com/jp/help/app-store-connect/manage-submissions-to-app-review/submit-an-in-app-purchase
- できない場合は**全画面のビデオ**を撮って提出する。
- アップロードリンクは `AppleSupport@email.apple.com` から受領済み（**7日間有効 / 2026-08-07 受信**）。

> 📌 これまで試したのは「App Review 画面からの再提出」と「API経由」の2つ。
> **「収益化 > サブスクリプション」から新バージョンへ紐づける正規ルートは未実施**。
> しかも 1.0.2 は公開済みで下書きが無かったため、そもそも試せない状態だった。

## 手順

### STEP 0｜録画を開始する

**`Win + Alt + R`**（画面右上に赤い録画バーが出る）。出なければ `Win + G` でゲームバーを開いて録画ボタン。

- **全画面**で撮る（Apple が「PCの画面全体を収録」と指定）
- **ゆっくり操作**する。早いと担当者が追えない
- **音声は不要**
- 1〜2分で十分

保存先: `ビデオ` フォルダの `キャプチャ`

### STEP 1｜新しいバージョン 1.0.3 を作る

1. App Store Connect → **Moffy** を開く
2. 左サイドバー **「iOSアプリ」の右の「＋」** をクリック
3. **「新しいバージョン」**（または iOS App）を選ぶ
4. バージョン番号に **`1.0.3`** と入力 → 作成

> ⚠️ **ビルドはまだ紐付けなくてよい。** 目的は「サブスクを追加できるか」の確認だけ。

### STEP 2｜★本命：収益化からサブスクを追加する

1. 左サイドバー **「収益化」→「サブスクリプション」**
2. **「Moffy Premium」** グループを開く
3. 右上の **「審査用に追加」** をクリック

**ここが分かれ道。**

| 結果 | 意味 | 次にすること |
|---|---|---|
| **押せた** | 🎉 解決。1.0.3 を選んで追加 | そのまま追加して、Apple に成功を報告 |
| **グレーで押せない** | 固着継続 | **その状態を3秒ほど映す**。それが Apple の求める証拠 |

### STEP 3｜録画を止めてアップロード

1. **`Win + Alt + R`** で終了
2. Apple から届いた **「Apple サポートにファイルを送信」のリンク**からアップロード（**7日間有効**）

下の文面をコピーし、**`【ここ】` を結果に応じて差し替える**。

## 🚫 やってはいけないこと

| 場所 | 禁止 | 理由 |
|---|---|---|
| App Review の 7/23 の提出物 | **「提出物を取り消す」** | 公開中のアプリが取り下げられる可能性がある |
| App Review の 7/23 の提出物 | **「App Reviewに再提出」の再クリック** | 効かないうえ、問い合わせスレッドが閉じるリスク |
| 収益化 > サブスクリプション | **「削除」ボタン** | 商品IDが永久に失われる。`moffy_premium_monthly` / `moffy_premium_yearly` は iOS・Android 両方の公開中アプリと RevenueCat に組み込み済みで、失うと両OS作り直し |
| 1.0.3 のページ | **「審査へ提出」** | まだビルドも v1.1 の修正も入っていない。**下書きのまま置いておく** |

## この 1.0.3 は v1.1 の受け皿になる

いま別セッションで進めている **v1.1（バグ修正の本丸）** の提出先が、この 1.0.3 になる。

