# Moffy SNS ローンチ投稿（X / Threads / Instagram）確定版

> 作成: マーケ/CEO（2026-07-27・公開直後）/ スコープ=リリース告知のSNS投稿
> オーナー指摘で是正: **#個人開発 はターゲットユーザーではなく開発者に届くタグ**。ユーザー獲得用と開発者コミュニティ用を分離した。
> 準拠: 実装済み機能のみ・景表法(数字/No.1/絶対/未実装機能なし)・オーナー本人の一次発信(ステマ規制対象外)。

## ターゲット（届けたい人＝ユーザー、開発者ではない）
1. **減らしたい層**: デジタルデトックス/スマホ依存/習慣化/自己管理 に関心。
2. **勉強・集中層**: 学生・受験生（**勉強垢**コミュニティ＝スマホを断ちたい最前線・巨大で高エンゲージ）。
3. **かわいいゲーム好き層**: 育成/収集ゲーム・かわいいキャラ好き。

→ **タグ/トピックはこの3層に向ける。#個人開発 はユーザー獲得には使わない**（開発者仲間の拡散を狙う"別ポスト"にのみ）。

## 投稿を2種類に分ける
- **A. ユーザー獲得ポスト（メイン）**: 悩み/ごほうびを先頭に。ターゲット層タグ。**#個人開発は入れない**。
- **B. 開発者コミュニティ・ポスト（任意・公開日のみ）**: 「個人開発でリリース」で仲間の拡散を得る。ユーザー投稿とは別に出す。

## 𝕏 X

### A. ユーザー獲得（メイン）
```

Moffy（モフィ）は、SNSやスマホを見なかった時間が、かわいいキャラ集めの"ごほうび"になる育成ゲーム📱🐣

制限もロックもなし。減らせた分だけ卵が育って、図鑑がうまっていきます。

iOS / Android・基本無料

#デジタルデトックス #勉強垢
```
- タグは**2〜3個まで**（Xは詰め込むと逆効果）。層を変えて複数回投稿する:
  - 減らしたい層向け: `#デジタルデトックス #スマホ依存`
  - 勉強層向け: `#勉強垢 #勉強垢さんと繋がりたい`
  - ゲーム好き層向け: `#育成ゲーム #新作アプリ`
- **リンクは本文でなくリプ（返信）に2つ**貼る（本文URLは表示が伸びるため）。

## 🧵 Threads

### A. ユーザー獲得（メイン）
```
スマホの見すぎ、やめたいけど我慢が続かない…そんな自分のために作りました。

「Moffy（モフィ）」は、SNSやスマホを見なかった時間がポイントになって、かわいいキャラ"Mofi"の卵が育つ育成×収集ゲームです🥚

制限したりロックしたりはしません。減らせた分がそのまま"ごほうび"になるので、責めずに続けられます。孵化したMofiを図鑑に集めていく楽しさも☺️

iOSもAndroidも、基本無料で遊べます。
```
- **トピック（1つ）**は**ターゲット層のもの**にする（"個人開発"は使わない）:
  - 第一候補: **`デジタルデトックス`**（価値に直結）
  - 学生を狙う日: **`勉強`**（母数が非常に大きい）
  - 代替: `習慣化`
  - → 別々の日にトピックを変えて投稿し、どの層が反応するか見る。
- リンクは本文に直接貼ってOK。

### B. 開発者向け（任意）: トピック `個人開発` で「個人開発でリリースしました」系を別途。

## 運用の考え方（1回で終わらせない）
- **1投稿=1ターゲット層**で、日を変えて出し分ける（減らしたい層／勉強層／ゲーム好き層）。どの層が伸びるかを見て寄せる。
- 反応（保存/リンククリック/DL）を見て、伸びた層の言葉・タグに寄せる。
- 開発者向けポスト(#個人開発)は「拡散のブースト」目的で公開日だけ。ユーザー投稿と混同しない。
